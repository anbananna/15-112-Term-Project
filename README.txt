Dimensional Drawer is an application that allows users to draw three dimensionally, 
tracking the position of the user's motion and depth from just a webcam. Users can view
and interact with their creations, easily rotating and zooming in and out of the
finishing graph. 


This application should be run on a device that has either an integrated webcam or 
one that can be connected to it. Please do not use your webcam for other uses while 
running this app as it will interfere with the program. The application file and 
directory with all of the images should be under one file. Do not change the names 
of the images or "images" file name! The app runs smoothly in Visual Studio Code 
and may work in other environments.


If the user does not have a certain module installed or implemented, a Module Manager
should be automatically set up to aid with that process. The Module Manager will be
able to detect which modules need to be set up and a separate window will show
regarding this.
Modules necessary: pygame, cv2, sys, time, random, argparse, imutils, collections, os, math


To run this program, simultaneously press your 'Ctrl' and 'B' keys. This should
start the application. After this, the application should guide you through what to
do and expect.


Lastly, have fun! This ws an app inspired by the limitations of only being able to
see in two dimensions while living in a three-dimensional world. Cheers to the crazy
way life is experienced. :^)
